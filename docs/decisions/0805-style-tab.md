# 0805: A Style tab for pace, cuts and caption look

Status: accepted, 2026-10-18

**Decision.** The editor's bin has a Style tab: a speed slider (70% to 130%), three pause presets (Tight
0.08 s, Natural 0.15 s, Relaxed 0.3 s, which call the re-cut endpoint), the three cut styles, an end fade
slider, a grid of the ten caption fonts each drawn in its own face, and caption size, colours, caps,
position and animation.

**Alternatives.** Put these in the inspector (it is for the selected block). Only offer them through the
AI box (not discoverable).

**Why.** These are whole-reel choices people want to try and compare, and the preview updates live.

**Consequences.** Every change is one undo step. The same settings are reachable from the AI box.
